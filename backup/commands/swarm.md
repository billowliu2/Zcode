[swarm 模式] 用户已明确要求用并行子代理批量执行以下任务。在采取任何其他行动（包括阅读文件、加载技能、编写代码）之前，你必须先启动 swarm 工作流：

1. 调用 `CreateWorkflow`，源用 `saved: { name: "swarm", args: {...} }`
2. 构造参数：把任务拆分为**相互独立、互不重叠**的子任务，`items` 列出各子任务的差异部分，`prompt_template` 用 `{{item}}` 占位符书写共享指令（含输入、预期输出、完成判据），所有子任务都需要的背景放 `shared_context`
3. 拆分没把握时先跑一次 `dry_run: true` 检查展开后的每条 prompt，再正式执行
4. 等工作流完成后，把逐项结果汇总为最终答案

禁止自己逐个完成本可并行的子任务。只有当任务本质上是串行的、确实无法安全并行化时，才简要说明原因并按普通方式执行。
