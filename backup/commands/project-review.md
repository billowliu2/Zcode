[project-review 模式] 用户要对项目做全面体检。调用 `CreateWorkflow`，源用 `saved: { name: "project-review", args: {...} }`：

- `path`：体检范围（工作区相对路径），取用户参数，留空传 "."（整个工作区）
- `dimensions`：通常留空用内置六维；用户点名了特定维度才传自定义列表
- 产出为带证据与严重度的体检报告（REVIEW-日期.md），发现属**候选问题**——报告回来后向用户转述结论，并提醒采纳修复前值得抽验证据

边界：这是**整个项目的当前状态体检**；用户要复核"刚做完的某次任务"时用 /task-review，不要用本命令。
